# JUDGE v0.3.0 — отчёт проверок

Дата: 22 октября 2026. Стенд: Node.js 22.16.0; Chromium через Python Playwright; изолированная SQLite в тестах.

## Автоматические проверки

- **91 из 91 пройдено**, `npm test`. Домен, реальный HTTP и cookie/CSRF/Host/Origin, сервис, миграция, интеграции, фейковый Responses API, snapshots/replay, backup.
- Новые 15 проверок: манифест и HTTPS, нулевое раскрытие секретов из оператора, версии handoff, ручной отзыв, отзыв после reopen/возражения, отказ после redeem, legacy unversioned отказ, подтверждение external callback, idempotency и конфликт повторного ID, SQLite schema v1→v2, запрет публичного HTTP и обмен по реальным локальным HTTP endpoints с **синтетическим** партнёром.
- `npm run integrations:check` на стандартной конфигурации: 7 записей, **0 подтверждённых подключений** (ожидаемо). Ни один внешний сайт не опрашивался.

## Браузерные проверки

- **20 из 20 пройдено**, `python scripts/browser-smoke.py`. Все три пути JUDGE, сохранение, приглашение реального второго test-actor, повторный пересмотр, аналитика, XSS, отзыв signed handoff и корректная маркировка clipboard, регистрация.
- Проверен page-level horizontal overflow на ширинах **390, 768, 1440 px**, на семи экранах; ошибка JavaScript отсутствует.
- Браузерный стенд работает с кодом из `public/` и настоящим локальным HTTP-сервером через тестовый мост, так как управляемый Chromium здесь блокирует обычную сетевую навигацию. Это **не** равносильно полноценному публичному browser E2E на staging.
- Отдельный `python scripts/offline-preview-smoke.py`: HTML single-file без backend проходит создание → вердикт → честный clipboard handoff и отображает историю.

## Корректность подсчётов и ограничений

- Только событие, подтверждённое авторизованной внешней платформой согласованного типа, становится `useful_action`. Копирование, клик по кнопке, открытие сайта и даже получение брифа **не являются подтверждением созданной рекламы**.
- Наличие callback с доступным секретом — техническое подтверждение партнёра, **не независимая проверка рекламного результата**.
- Real OpenAI API call и реальные 7 площадок не тестировались: их ключей и контрактов в сборке нет. Платежи, SSR, SSO, PostgreSQL, облако и безопасность production инфраструктуры не объявлены готовыми.
- Все QA-секреты фиктивные. Не включены клиентские секреты реальных сайтов.

