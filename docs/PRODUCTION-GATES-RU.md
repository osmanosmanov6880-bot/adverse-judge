# Оставшиеся эксплуатационные ворота (не сделано в 0.10.0)

Дальнейшая разработка не должна начинаться с обещания «мировой SaaS уже готов». Ниже проверяемые инженерные ворота:

| Gate | Что требуется | Критерий приемки |
|---|---|---|
| P1 Identity | подтверждённые email, восстановление доступа, MFA, SSO (при необходимости), аудит сеансов и строгая привязка корпоративных ролей | тесты отозванного сеанса, смены адреса, чужих организаций, восстановления и MFA; zero BOLA |
| P2 Database | PostgreSQL + подготовленные миграции, транзакционная событийная история и проверка совместимости экспорта SQLite | сравнение replay до/после миграции на реальных копиях; backup/restore + журнал |
| P3 External contracts | адреса A–G, реализуемые API, авторизация и ключи, sandbox каждого сайта, идемпотентность, событие `ad_created` | отдельный signed e2e с каждым сайтом; никакого фиктивного useful_action |
| P4 Localization | полный RU/EN/zh текст, подсказки, ошибки, ввод, даты, доступность и правовая документация | языковой аудит интерфейса, тесты на мобильной ширине и WCAG |
| P5 Privacy/security | privacy notice, retention, DSAR/delete/export, DPA, anti-fraud, security review, мониторинг и rate limiting | независимый security test, incident drill, offsite encrypted backup с восстановлением |
| P6 Product validation | реальные команды агентств, спрос, допустимая цена, SaaS-воронка | фактические регистрации, использование, платящие B2B клиенты — не демо-данные |

До прохождения Gate P1/P2/P5 запуск для широкой аудитории недопустим. Выкладка на сервер не должна смешиваться с разработкой и проверкой прототипа.


## Дополнение v0.20.0

Наличие WAVE 11–15 **не закрывает** публичные требования: нет верифицированной личности, Postgres/SSO/MFA, внешних резервных копий, 7 реальных партнёрских интеграций, юридической проверки рекламы или измеренных результатов клиентов. Локальные демонстрационные данные не подтверждают спрос или эффективность. `npm run ops:doctor` должен сохранять `productionReady=false` до отдельного production-релиза.

## Дополнение 0.30.0 — WAVE 21–25

- Почтовое подтверждение: провайдер реально доставляет письма, коды одноразовые и тайм-аут проверен; необходимость подтверждения включена после безопасной миграции старых аккаунтов.
- Восстановление пароля: закрыто перечисление аккаунтов, ротируются все сеансы, установлены лимиты и журнал инцидентов.
- CSV: пользователь подтверждает непроверенное происхождение и не может повторно импортировать один и тот же набор.
- Партнёры A–G: живые договоры и серверные callback доступны только после conformance, whitelist egress, разрешения домена и HTTPS/TLS. В 0.30.0 подтверждено только локальное HTTP моделирование (не реальные сайты).
- Очередь: требуется production-grade распределённая lease-координация и внешнее расписание; пример приёмника с in-memory ключами недостаточен для настоящего партнёра.
- Резервная копия: manifest + SHA-256 + независимое восстановление и replay, не только наличие файла. Также нужен зашифрованный off-site backup и проверенное восстановление на отдельном сервере.
- Производственная авторизация, PostgreSQL/HA, независимое тестирование безопасности и нагрузки, полное соблюдение действующих правил конфиденциальности — **НЕ ПРОВЕРЕНЫ**.
